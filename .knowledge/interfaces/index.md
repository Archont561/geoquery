# Interfaces

Every way a user, application, or AI agent interacts with the engine.

* [CLI Interface](cli.md) - geoquery add, query, sources, explore — command-line UX.
* [HTTP API](http.md) - POST /query, resource CRUD, SSE streaming, OpenAPI spec.
* [MCP Server for AI Agents](mcp.md) - geo_query, geo_resource, geo_resolve tools; rmcp 3.x; 2026 spec.
* [TUI — Interactive Terminal Interface](tui.md) - ratatui TUI — result browser, source dashboard, ASCII map.
* [TypeScript SDK — @archont561/geoquery](typescript.md) - Native N-API package over the Rust core; HTTP is a separate interface.
* [Python SDK — geoquery](python.md) - geoquery Python SDK, GeoPandas integration, PyO3 path.
