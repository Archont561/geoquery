## Description

Turn Geoquery's Phase 0 document reader into a usable single-source STAC client: a canonical query model, an adapter contract, a persisted source registry, a STAC search path, normalized results with provenance, and an honest CLI. The exit demo is a real STAC query that returns normalized results rather than exit code 3.
